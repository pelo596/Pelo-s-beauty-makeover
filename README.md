# Pelo's Beauty Makeover

A responsive, single-page beauty and styling guide built with HTML, Tailwind CSS via CDN, and vanilla JavaScript. No install or build step is required.

## Deploy on Render

This repository includes a Render Blueprint in `render.yaml`.

1. In Render, choose **New +** → **Blueprint**.
2. Connect this GitHub repository.
3. Review the `pelos-beauty-makeover` static site and select **Apply**.

Render publishes the repository root, where `index.html` is located. After setup, pushes to the connected branch trigger a redeploy.

Alternatively, create a **Static Site** manually with the repository root as the publish directory and `echo "No build step required"` as the build command.
